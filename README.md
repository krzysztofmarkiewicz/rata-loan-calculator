# Kalkulator Kredytowy (Toolbox)

Nowoczesna aplikacja internetowa do precyzyjnej symulacji rat i całkowitych kosztów kredytu gotówkowego oraz hipotecznego.

## Funkcjonalności

- **Dwa systemy spłat**: Raty równe (annuitetowe) oraz raty malejące.
- **Obliczenia w czasie rzeczywistym**: Natychmiastowa aktualizacja wyników przy zmianie parametrów.
- **Interaktywne suwaki i szybkie presety**: Wygodne wprowadzanie kwot i okresów (lata/miesiące).
- **Szczegółowy harmonogram spłat**: Rozwijana tabela ze strukturą każdej raty (kapitał, odsetki, pozostały kapitał do spłaty).
- **Wizualna struktura kosztów**: Pasek podziału kwoty spłaty na kapitał, odsetki i prowizję banku.
- **Kopiowanie podsumowania**: Eksport kluczowych informacji do schowka jednym kliknięciem.
- **Motyw jasny i ciemny (Dark Mode)**: Płynne przełączanie z zapamiętywaniem preferencji w `localStorage`.
- **Wydruk / Eksport do PDF**: Dedykowane style `@media print`.
- **Responsywny design**: Pełna obsługa urządzeń mobilnych i desktopowych.

## Technologie

- HTML5, Vanilla CSS3 (Glassmorphism, CSS Custom Properties), JavaScript (ES6+).
